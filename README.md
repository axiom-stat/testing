# CeramScan («КерамикСкан»)

Локальный прототип оптического контроля качества фарфора по ГОСТ 28390-89 и цифрового паспорта ручной кобальтовой росписи под 289-ФЗ для производств народных художественных промыслов на примере Объединения «Гжель». Проект работает на обычном CPU (среднее время кадра 80.49 мс при пороге 300 мс) без дорогих промышленных камер, видеокарт и облачных сервисов.

Проект подготовлен индивидуально для 4-го сезона Стипендиального конкурса БФ «Система» (номинация 2.3.9 «Технологии в креативных индустриях и народных промыслах», дедлайн 30 ноября 2026 года).

## Замеры точности и скорости (`синтетический валидационный стенд v0.1`)

Текущие показатели измерены скриптом `scripts/run_benchmark.py` на `синтетический валидационный стенд v0.1` (`26` образцов семи классов и `4` пары подлинности, данные сохранены в `reports/benchmark_results.json`), а фильтры калибровались на четырех эталонных фото дефектов керамики из `data/reference_materials/`.

| Показатель | Измеренное значение | Порог или пояснение |
|---|---|---|
| Выборка дефектов (`sample_count`) | `26` кадров | `12` pass, `6` crack, `2` chip, `2` glaze_bare, `2` shape_warp, `1` glaze_drip, `1` pinhole_speck |
| Среднее время на кадр (`avg_latency_ms`) | `80.49 мс` | Более чем в 3 раза быстрее SLA `< 300 мс` на CPU |
| 95-й процентиль времени (`p95_latency_ms`) | `137.06 мс` | Режим `model_mode = "deterministic"` |
| Метрики классов (`precision`, `recall`, `f1`, `verdict_accuracy`) | `1.0` / `1.0` / `1.0` / `1.0` | Триаж `PASS` / `REWORK` / `REJECT` по правилам 1-го сорта ГОСТ 28390-89 |
| Сверка подлинности 289-ФЗ (`auth_accuracy`) | `1.0` (`4` пары) | Подлинник в среднем `86.87%` против `38.39%` у штамповки (порог `>= 62.0%` и `>= 12` точек RANSAC) |

## Архитектура, API и три режима веб-интерфейса

Логика компьютерного зрения вынесена в `src/cv_core/` и разделена на препроцессинг с маской бликов `L > 235 & S < 30` и маской кобальта (`HSV` + `LAB b* < 118`), гибридный детектор дефектов на базе Black-Hat и фильтра Сато с точкой `--weights` под `.onnx`, модуль оптического отпечатка `0.50 * ORB + 0.25 * pHash + 0.25 * cobalt_hist` (устойчив к переклейке стикера Data Matrix по ПП РФ № 1374 от 01.04.2027) и локальное хранилище SQLite WAL с выпуском QR.

Веб-интерфейс в `src/web/` (`src/web/index.html`, `src/web/styles.css`, `src/web/app.js`) без фронтенд-сборки работает поверх `src/api.py` в трех режимах:

1. «Пост ОТК»: выбор этапа (`Утиль 900°C` / `Глазурь 1350°C`), фото с камеры смартфона или быстрый образец, интерактивная шторка «Сравнение / Исходник / Оверлей» и разбор дефектов по ГОСТ 28390-89
2. «Подлинность»: выпуск QR-паспорта и сверка фото с эталоном по индексу сходства и субметрикам `ORB`, `pHash` и `Палитра кобальта`
3. «Дашборд ОТК»: сводные KPI, доли брака по этапам и сменам и фильтруемый журнал SQLite

Сервер `src/api.py` обслуживает маршруты `GET /health`, `GET /api/demo-samples`, `POST /api/inspect`, `POST /api/passport/register`, `POST /api/passport/verify/{item_id}` и `GET /api/analytics`.

## Быстрый старт и команды CLI

Установка зависимостей в локальное окружение `.venv` и запуск веб-сервиса:

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn src.api:app --host 127.0.0.1 --port 8000
```

Основные сценарии генерации стенда, замера бенчмарка, пересборки на реальных фото и автотестов:

```bash
# 1. Сгенерировать синтетический стенд v0.1 (минимум 24 кадра)
.venv/bin/python scripts/generate_synthetic_ceramic.py --output-dir data/synthetic --count 26 --seed 42

# 2. Запустить бенчмарк (опционально подключить ONNX через --weights)
.venv/bin/python scripts/run_benchmark.py --dataset data/synthetic/manifest.json --output-json reports/benchmark_results.json --output-md reports/benchmark_summary.md --overlays-dir reports/overlays

# 3. Загрузить 20 - 30 реальных фото завода и пересобрать отчеты и презентацию
.venv/bin/python scripts/ingest_real_photos.py --input data/real_photos --rebuild-all
.venv/bin/python scripts/ingest_real_photos.py --input data/real_photos --export-yolo /tmp/ceramscan_yolo --weights path/to/model.onnx --rebuild-all

# 4. Собрать грантовые документы и запустить автотесты
.venv/bin/python grant_case/build_docx.py
.venv/bin/python grant_case/build_presentation.py
.venv/bin/python -m pytest
```

Детальная инструкция по съемке реальных образцов и чек-лист подготовки к подаче до 30 ноября 2026 лежат в `grant_case/REFINEMENTS_ROADMAP.md`. Для публикации в GitHub привяжите удаленный репозиторий и отправьте основную ветку:

```bash
git push -u origin main
```
